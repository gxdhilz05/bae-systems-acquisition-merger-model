# Stage 0: Project Map

## What the project must prove

The project must answer four distinct questions:

1. **Strategic fit:** Would the target add capabilities, technologies, customers or market access that BAE values?
2. **Valuation:** What is the target worth independently, and what purchase price can BAE justify?
3. **Financing:** Can BAE fund the transaction without creating excessive leverage or dilution?
4. **Value creation:** Are the target's earnings and achievable synergies sufficient to offset the premium, financing costs and purchase-accounting effects?

## Transaction logic

```text
Select target
    -> value target
    -> set offer price
    -> choose cash/debt/shares
    -> calculate purchase accounting
    -> combine earnings
    -> add synergies and financing effects
    -> calculate EPS and leverage
    -> test sensitivities
    -> recommend proceed, renegotiate or reject
```

## Three rules for every section

Before a section is added to the final model, be able to answer:

1. What are we calculating?
2. Why are we calculating it?
3. What does the result tell BAE?

## Key distinction

A strategically attractive target is not automatically a financially attractive acquisition. BAE can destroy value by paying too much even when the target is an excellent operational fit.

## Completion test for Stage 0

Explain, without formulas, why the model must account for:

- the takeover premium;
- cash, debt and share financing;
- synergies;
- purchase-accounting amortisation;
- EPS accretion or dilution; and
- post-deal leverage.

Stage 1 begins only when the overall transaction logic is clear.
