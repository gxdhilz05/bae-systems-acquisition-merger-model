# Model Folder

The workbook is being added in controlled stages rather than generated as a finished black box.

The first version uses Cohort, the preferred target from the evidence-backed screen. It is an illustrative acquisition calculator and teaching model. It will be expanded as valuation, forecasts and purchase-accounting assumptions are developed.

Version 1 tabs:

1. `Summary`
2. `Assumptions`
3. `Screening`
4. `Deal`
5. `Earnings`
6. `Leverage`
7. `Sources & Guide`

Every assumption will be clearly distinguished from sourced historical data and formula-driven outputs.

The workbook is generated by `build_model.mjs`. Later versions will add the standalone forecast, valuation, purchase accounting, detailed accretion/dilution and sensitivities.
