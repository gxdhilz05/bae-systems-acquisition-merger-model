# Model Folder

The workbook is being added in controlled stages rather than generated as a finished black box.

The model uses Cohort, the preferred target from the evidence-backed screen. Version 2 adds a deliberately simple five-year forecast, DCF and synergy-supported price ceiling while keeping the acquisition calculator transparent.

Version 2 tabs:

1. `Summary`
2. `Assumptions`
3. `Valuation`
4. `Screening`
5. `Deal`
6. `Earnings`
7. `Leverage`
8. `Sources & Guide`

Every assumption will be clearly distinguished from sourced historical data and formula-driven outputs.

The workbook is generated by `build_model.mjs`. The next version will add simple purchase accounting and offer-price sensitivities.
