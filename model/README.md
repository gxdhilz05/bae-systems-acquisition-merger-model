# Model Folder

The workbook is being added in controlled stages rather than generated as a finished black box.

The model uses Cohort, the preferred target from the evidence-backed screen. Version 3 adds simplified purchase accounting and offer-price sensitivity to the existing forecast, DCF and acquisition calculator.

Version 3 tabs:

1. `Summary`
2. `Assumptions`
3. `Valuation`
4. `Purchase Accounting`
5. `Screening`
6. `Deal`
7. `Earnings`
8. `Leverage`
9. `Sources & Guide`

Every assumption will be clearly distinguished from sourced historical data and formula-driven outputs.

The workbook is generated by `build_model.mjs`. The next stage is the final recommendation and interview explanation rather than additional model complexity.
