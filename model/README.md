# Model Folder

The workbook is being added in controlled stages rather than generated as a finished black box.

The model uses Cohort, the preferred target from the evidence-backed screen. Version 4 adds simple comparable-company and precedent-transactions valuation cross-checks to the forecast, DCF and acquisition calculator.

Version 4 tabs:

1. `Summary`
2. `Assumptions`
3. `Valuation`
4. `CCA & PTA`
5. `Purchase Accounting`
6. `Screening`
7. `Deal`
8. `Earnings`
9. `Leverage`
10. `Sources & Guide`

Every assumption will be clearly distinguished from sourced historical data and formula-driven outputs.

The workbook is generated by `build_model.mjs`. The CCA and PTA use a deliberately small peer and transaction set so the valuation logic remains easy to explain. The next stage is the final recommendation and interview explanation rather than additional model complexity.
